# MoveMatch: AI-Assisted Location Recommender

## Overview

MoveMatch is a small AI-assisted tool that helps people explore potential places to move based on their personal preferences.  
A user types a short description of what they want in a place to live (for example, affordability, access to parks, good air quality, or racial diversity), and the system suggests U.S. counties that best match those preferences using a county-level quality-of-life dataset. The goal is to make relocation decisions easier and more transparent by connecting subjective preferences to real data.
